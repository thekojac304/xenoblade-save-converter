# Three-way compatibility (XC Save Converter 3A-rc1)

Platforms: **Wii** (Xenoblade Chronicles, SX4E, Dolphin) · **DE** (Definitive Edition save format v10, Monado) ·
**3DS** (Xenoblade Chronicles 3D, KTR-P-CAFE USA v1.0, Azahar; real New 3DS via Checkpoint).

Status words: **VALIDATED** = generated saves loaded and played (menus, combat or travel, in-game save, reload) in the
emulator with no loss · **PARTIALLY VALIDATED** = loads and saves in the emulator, but a listed part of normal play
is not yet covered · **EXPERIMENTAL** = static checks only · **UNSUPPORTED**. Hardware (real New 3DS) is listed
separately because nothing was tested on hardware.

Round trips (static, byte-level, real saves): Wii → 3DS → Wii, 3DS → Wii → 3DS, DE → 3DS → DE, 3DS → DE → 3DS,
Wii → DE → 3DS → (Wii, DE) all return the original bytes when nothing was played in between. With play in between,
only the played progress differs (canonical comparison).

## 2. Requirements per direction

| Direction | Your save | Destination save (step 2) | Conversion record |
|---|---|---|---|
| Wii → DE / DE → Wii | as 2H | DE template / Wii base (first) or current save (return) | 2H sidecar |
| Wii → 3DS | Wii `monado0N` | **a 3DS save** (any, only read): supplies the picture | optional; found automatically |
| 3DS → Wii | 3DS `monado0N` | not needed (first); your current Wii save (return, for safety) | optional |
| DE → 3DS | DE v10 | **a 3DS save** (structural base, ideally similar chapter) | optional (return trip) |
| 3DS → DE | 3DS `monado0N` | a DE v10 save (first) or your current DE save (return) | needed for a return trip (keeps DE-only data) |

## 4. Not supported

* 3DS saves of other regions/versions (only USA v1.0 was available; the converter checks the format, not the region).
* `specialmode` (Special Mode / extras file) is not a playthrough slot and is not converted (it is copied unchanged
  inside a Checkpoint archive folder).
* Writing directly to an SD card, an emulator's save folder or a game folder (refused by design).
